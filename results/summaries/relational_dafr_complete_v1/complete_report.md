# 联合风险曲面：升级结构化流程实验

**结论范围：支持升级联合风险曲面对本实验所测线性评分和有限线性条件组合的优势。不是原版 DAFR 完整语义流程的消融，也不是普遍优越性证明。**

## 数据构造与方法

- 4,800 条样本：960 个基础实例，每例包含未核验、精确授权、无关授权、过期授权、来源伪造授权五个版本。四类图拓扑分别对应支付、文档发布、记录修改和权限变更；它们是声明的合成过程，不是采集的真实业务分布。
- 基础实例按组划分：训练 2,400 条、开发 1,200 条、测试 1,200 条。相同实例的五个版本不跨集合；没有按结果筛掉样本。
- 每个字段的来源传播链必须同时激活才形成未授权影响；任一未授权链激活即产生该动作的损失。独立原始事件可被多条链共享，由此产生路径间相关性。独立模拟器枚举事件世界生成标签。
- 曲面计算“任一未授权链激活”的联合概率乘以后果严重度，以风险预算判定。它不是逐项损失相加，也不是原版二阶风险锥；非凸曲面由依赖图确定。作用域、精确值、来源身份和当前版本均参与授权匹配。
- 输入只暴露按两位小数取整的事件测量、误差半径和结构化链路记录。潜在真值、标签和核验许可账本分别保存在 evaluator/labels 文件；控制器只收到 public input 和真实模拟核验回复。
- 核验可能拒绝并消耗预算；允许后执行原动作，独立执行器记录风险预算是否被突破。安全成功表示完成动作且期望未授权损失不超过预算，不表示每次随机事件都无损害。
- 所有线性对照共享 32 维概率/图成员关系/严重度/预算特征、授权处理、核验预算和字段次序。包含仿射评分及最多 4/16/64 叶的轴向线性条件决策树；阈值仅在开发集选择。feedback 对照额外使用训练/开发集的许可核验状态。
- 首轮诊断后增加了 feedback 对照和跨图族检查。没有修改测试样本或按测试选择阈值；这些结果仍属探索性实验，不能宣称外部预注册。

## 测试结果

所有结果以同一 1,200 条测试为分母；安全原始动作 404 条、不安全原始动作 796 条。核验后理论可恢复 725 条，完整方法实际安全完成 655 条，仍有 70 条恢复缺口。

| 方法 | 初始判定准确率 | 安全完成 | 越界执行 | 核验次数 |
|---|---:|---:|---:|---:|
| 完整升级曲面 | 99.17% | 655 | 0 | 776 |
| 线性评分 | 82.08% | 273 | 36 | 945 |
| 线性评分＋核验状态训练 | 73.92% | 349 | 46 | 1058 |
| 64 叶线性条件组合 | 81.75% | 240 | 51 | 908 |
| 64 叶规则＋核验状态训练 | 75.92% | 438 | 129 | 827 |
| 移除来源投影 | 96.67% | 635 | 70 | 697 |
| 移除依赖 lifting | 80.17% | 410 | 0 | 1034 |
| 移除动态状态更新 | 56.42% | 400 | 519 | 262 |
| 移除核验修复 | 99.17% | 394 | 0 | 0 |
| 把授权变成全局授权 | 61.00% | 450 | 608 | 260 |
| 忽略授权版本 | 96.67% | 637 | 40 | 745 |
| 把共享路径当独立 | 96.50% | 639 | 0 | 804 |
| 移除概率误差区间 | 99.92% | 659 | 5 | 749 |

已运行四模块全部 16 种开关组合，共 36 个实验配置、43,200 次测试流程。全部配置保存在 summary.json；包括严格安全校准规则拒绝全部初始动作的结果，没有只呈现有利对照。

移除核验修复不改变初始分类，而减少安全完成；因此不能只用分类准确率评价该模块。概率区间使初始误拦截增加至 10 条，但避免点估计产生的 5 次越界执行。

## 统计与泛化

按 240 个基础测试实例配对 bootstrap，4,000 次重采样。以下是完整方法减去线性对照的安全完成率差值；区间未经多重比较校正。

| 对照 | 安全完成率差值 | 95% 分组区间 |
|---|---:|---:|
| 线性评分 | 31.83 pp | [26.50, 37.25] pp |
| 线性评分＋核验状态训练 | 25.50 pp | [20.42, 30.67] pp |
| 64 叶规则＋核验状态训练 | 18.08 pp | [13.75, 22.58] pp |

每次从训练和开发中排除整个图族，使用带核验状态训练的对照，在该图族原测试集评估：

| 留出图族 | 曲面安全完成/越界 | 线性评分安全完成/越界 | 64 叶规则安全完成/越界 |
|---|---:|---:|---:|
| document_release | 154 / 0 | 79 / 30 | 99 / 149 |
| payment | 138 / 0 | 95 / 86 | 71 / 55 |
| permission_change | 147 / 0 | 83 / 37 | 57 / 88 |
| record_mutation | 216 / 0 | 103 / 1 | 100 / 68 |

这里的泛化是已知联合概率法则在不同声明图拓扑间的迁移。尚未证明自然语言依赖抽取、真实风险概率估计或未知风险法则上的泛化。

## 几何容量证据及局限

固定同一动作、同一授权和同一传播链：概率 (.9,.1) 与 (.1,.9) 的独立世界风险都是 .09，低于 .15；特征中点 (.5,.5) 风险 .25，超出预算。任何接受两个端点的凸半空间交都必接受中点，而本联合曲面能区分三者。可达特征和独立世界数值保存在 convex_capacity_witness.json。这个证据不排除多个线性区域的并集近似。

正确指定的联合概率算式与曲面本质等价。因此实验证明的是联合非线性风险表示相对于指定线性表示的贡献，不能证明“几何”相对于同等非线性算术规则有独立优势。

真实化尚缺：自然语言链路抽取、事件概率校准、超出声明模型的环境失配、大图计算扩展。原始事件独立性是建模假设；共享事件造成的相关性已处理，其他相关性未处理。四模块对应新结构化控制器，并非生产 DAFR 的原始实现开关。

## 文件与复现

- 数据：data/relational_dafr_complete_v1/，inputs 为控制器输入，evaluator 为隐藏环境状态，labels 为独立标签；manifest.json 记录哈希和协议。
- frozen_protocol.json：模型参数、开关配置、源码哈希及诊断后新增对照的说明。
- integrity_audit.json：逐条独立标签重算、组划分和文件哈希检查；paired_intervals.json 与 heldout_graph_families.json 保存详细结果。
- 运行 scripts/run_relational_dafr_complete_ablation.py，再运行 scripts/audit_relational_dafr_complete.py 和本报告脚本。依赖 numpy、scikit-learn；执行前设置 OPENBLAS_NUM_THREADS=1、OMP_NUM_THREADS=1 可避免小矩阵多线程开销。
- 新环境安装：pip install -e ".[dev,relational-benchmark]"；冻结协议记录实际 Python、numpy、scikit-learn 版本。
- 本轮相关测试共 90 项通过；test_relational_pipeline.py 覆盖拒绝核验、预算、隐藏标签隔离、来源伪造、独立执行安全和输入不变性。
